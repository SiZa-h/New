# Security Policy

## Supported versions

Only the latest stable release is considered for security fixes. Please upgrade to the latest release before reporting an issue.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues, discussions, or pull requests. Use GitHub's private vulnerability reporting feature on this repository's **Security** tab when it is available. If private reporting is not enabled, contact the maintainer privately through the contact options on the [maintainer's GitHub profile](https://github.com/SiZa-h).

Include the affected version, impact, and steps to reproduce. Avoid sending unrelated personal or sensitive information. The maintainer will acknowledge reports when practicable, investigate them, and coordinate any fix or public disclosure with the reporter.

# 安全政策

## 支持版本

安全修复仅针对最新稳定版本考虑。提交问题前，请先升级到最新版本。

## 报告漏洞

请勿通过公开 issue、讨论区或拉取请求报告漏洞。若本仓库已启用 GitHub **Security** 标签页中的私密漏洞报告功能，请使用该功能；若未启用，请通过[维护者的 GitHub 个人主页](https://github.com/SiZa-h)提供的联系方式私下报告。

请提供受影响版本、影响范围及复现步骤，避免发送无关的个人或敏感信息。维护者会在条件允许时确认收到报告、进行调查，并与报告者协调修复或公开披露。
